# medsam-research

基于 SAM 2.1 的医学图像分割研究项目。

## 当前状态

项目骨架，尚未实现训练与推理，也未获得实验结果。候选研究问题是：何时应进行局部高分辨率重读，何时应进行参数适配？其新颖性和有效性尚待验证。

## 实施顺序

1. 固定官方 SAM 2 代码提交与 SAM 2.1 Hiera-Small 权重版本。
2. 实现数据读取、自动分割入口、训练及独立评估。
3. 在同一基线上实现原图局部重读与 LoRA 对照。
4. 分析两种动作的收益是否互补，再决定是否实现动作收益预测。

无标签测试时适配目标尚未确定，不将普通监督微调等同于测试时适配。

## 项目结构

- `configs/experiment.example.yaml`：实验设置模板。
- `src/medsam_research/`：后续实现代码。
- `EXPERIMENTS.md`：实验协议与记录要求。

数据、权重、凭据与运行输出不得提交 Git。数据路径使用本机绝对路径或环境变量。

## 开发约定

以独立提交记录可运行修改；主分支保持可复现。每次实验记录代码提交、权重版本、数据划分与随机种子。未实现功能须明确标注，不生成虚构结果。
