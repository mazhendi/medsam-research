# 息肉分割：协议核对与强基线选择（2026-11-21）

本报告区分论文报告、作者公开代码和本项目实测。论文成绩不是本项目复现成绩；目前未在相同数据和评估协议下完成下列强基线训练，不能宣称某个模型是本项目最优。

## 1. 已核对的方法

| 方法 | 来源与定位 | 数据与实现要点 | 用途 |
|---|---|---|---|
| PraNet | MICCAI 2020；协议参照 | 通用训练池 Kvasir 900 + ClinicDB 550；352；官方训练默认 batch 16、20 epochs、Adam 1e-4；尺度 0.75/1/1.25 | 理解标准五集协议，不作为新的主基线 |
| Polyp-PVT | CAAI AIR 2023；公开代码 | PVTv2-B2；352；batch 16；AdamW 1e-4；论文 100 epochs；尺度 0.75/1/1.25；官方增强开关默认关闭，不能把多尺度训练等同于 light 增强 | 强任务专用参照 |
| MEGANet | WACV 2024；公开代码 | 多尺度边缘引导；官方 Res2Net 训练默认 352、batch 16、200 epochs、SGD 1e-3；旋转、翻转；尺度 0.75/1/1.25 | 边界方法参照 |
| SAM2-UNet | Visual Intelligence 2026；公开代码 | SAM2 Hiera-L；352；batch 12；20 epochs；AdamW 1e-3、余弦调度；翻转；论文另列尺度 1/1.25 | 优先复现的基础模型路线 |
| DSCNet | IEEE TIM 2026；用户提供全文 | PVTv2；论文训练 900+548，测试 ClinicDB 64；352；batch 16；100 epochs；AdamW 5e-5；多尺度、翻转/旋转 | 强结果与模块设计参照；本轮未核实官方代码 |
| DEPR-Net | KBS，2026-10 在线，卷期 2027；用户提供全文 | PVTv2-B2 + SegMAN-S；900+550；352；batch 18；Adam 8e-5、余弦至 1e-5；所读实现说明中未明确找到训练轮数 | 强结果参照；本轮未核实官方代码 |
| EAT | IEEE TMI 2026；公开代码 | PVTv2-B2 与 DCNv4；公开配置存在单数据集 80/20 设置及 num_epochs=4000 | 候选；须先核对五集协议，不能直接拿其单集成绩排序 |

作者代码的默认参数不保证就是论文全部实验所用参数。SAM2-UNet 当前公开训练循环没有论文描述的 1/1.25 多尺度循环；Polyp-PVT 默认 epoch=100 但循环上限不含 100。精确复现必须注明这些差异。

## 2. 当前数据协议不能直接等同于标准表格

常见训练池为 1450 张（900 Kvasir + 550 ClinicDB），测试数量依次为 100、62、60、380、196。DSCNet 的 ClinicDB 划分为 548/64，是明确的例外。

本项目从 1450 再划出 145 验证，实际训练 1305。当前报告测试数量为 100、62、58、346、193。评估脚本读取 `*_dedup.csv`，因此数量减少可能来自主动去重，尚未在此环境拿到原始数据清单确认，不能笼统判为缺图。

下一步应列出每张排除图及理由，检查重复图、跨划分重叠、配对失败和尺寸不匹配。不要直接恢复所有被排除图。文献协议与去重协议可以分别报告，但每个协议内所有模型必须评估同一清单。外部测试图不得用于训练、调阈值或选轮次。

只有源域验证集时，可先锁定超参和轮数，然后在正式对比中统一训练预算；若使用完整 1450 训练，需说明选模规则，而不是继续用已经加入训练的 145 张选模。

## 3. 概率图的处理差异

本项目 `tools/predict_probs.py` 导出 sigmoid(logit)，四舍五入至 8-bit；`tools/eval_hsnet_metrics.py` 对 256 个阈值求均值。Polyp-PVT 和 SAM2-UNet 的公开预测代码还执行每图 min–max 归一化。即使都称为“概率图指标”，两者仍不同；归一化会影响阈值平均 Dice/IoU 等，可能改变固定 0.5 掩码。

需要分别记录：原图分辨率、上采样位置与参数、是否 min–max、8-bit 转换、逐图平均还是像素汇总、mean/max/adaptive E-measure、空预测的 HD95 约定。保留原始概率指标作为校准与固定阈值参照。不能用更换后处理获得的增益证明模块有效。

增强也不能简单规定“全部一样”：例如 SAM2-UNet 作者数据加载器对 mask 使用 bicubic，形成软标签。忠实复现需保留并说明；改为最近邻属于协议变更，应单独记录。

## 4. 选基线的结论

优先复现 SAM2-UNet，配套复现 Polyp-PVT。前者已发表、有公开代码、论文直接使用单张 4090；后者是息肉任务的强且成熟参照。不能因为前者用了基础模型，就预设它一定胜出。

按各自论文表格，统一顺序 Kvasir/ClinicDB/CVC300/ColonDB/ETIS：

| 方法 | Dice（论文报告，未在本项目统一复现） | 五集宏平均 |
|---|---|---|
| Polyp-PVT | .917/.937/.900/.808/.787 | .8698 |
| SAM2-UNet | .928/.907/.894/.808/.796 | .8666 |
| DSCNet | .927/.946/.905/.814/.812 | .8808 |
| DEPR-Net | .924/.944/.916/.818/.814 | .8832 |

这些数字只能提供目标区间，不能绕过前述协议差异直接当成公平排名。

SAM2-UNet 路径是：冻结 SAM2 Hiera-L 原始参数，在编码块加入可训练 Adapter，使用可训练 RFB/UNet 解码器与深监督；移除原 SAM 提示/掩码解码器及记忆组件。它与本项目冻结 SAM2.1 Small 编码器、沿用 SAM 解码器的路径不同。官方仓库说明使用 SAM2 权重，不应直接替换为 SAM2.1 后仍称原版复现。

## 5. 复现后再改什么

研究主题限定为息肉的尺度变化、弱边界与跨数据集泛化，暂不增加文本或新模态。先建立两个强基线在一致协议下的结果，再决定主模型；保留当前模型和权重作对照。

小目标桶的 -0.0362 是当前模型的重要失败信号，但尚不能证明是唯一成因或普遍规律。应在新基线上复查面积桶、整图漏检、召回、边界指标及粗到细各层响应。测试集面积分桶仅作事后诊断，不能用测试标签控制推理路由。

若新的强基线仍存在粗尺度语义压制小息肉的现象，再研究高分辨率证据如何参与跨尺度更新，并以无新增结构、参数量匹配普通融合、采样增强、拟议模块作对照。先明确可检验机制，再给模块命名和绘图；不以堆叠卷积、注意力或 Mamba 本身作为创新结论。
