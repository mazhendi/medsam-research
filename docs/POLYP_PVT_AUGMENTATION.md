## 固定策略 polyp_light，版本1

RGB和掩码先沿用原流程双线性缩放到352，再执行以下操作，最后RGB做ImageNet标准化。

| 操作 | 概率/范围 | 对掩码的处理 |
|---|---|---|
| 水平翻转 | 0.5 | 同步 |
| 垂直翻转 | 0.5 | 同步 |
| 90度倍数旋转 | 0.5；等概率选择90/180/270度 | 同步，无额外插值 |
| 外观扰动组合 | 0.5 | 不改变掩码 |
| 组合内亮度 | 系数均匀采样[0.9,1.1] | 不改变掩码 |
| 组合内对比度 | 系数均匀采样[0.9,1.1] | 不改变掩码 |
| 组合内饱和度 | 系数均匀采样[0.95,1.05] | 不改变掩码 |
| 组合内Gamma | 指数均匀采样[0.9,1.1]，p'=p^gamma | 不改变掩码 |

亮度/对比度/饱和度三操作随机排序，Gamma最后执行；外观组合发生时均应用这四项。
不做裁剪、目标居中、缩小填充、形态学修改、模糊或遮挡；不使用ETIS或其他测试统计。
掩码仍为原基线的双线性软目标，不改成硬阈值/最近邻，避免同时改变标签协议。
同一次取样的增强结果用于该批次的三个尺度更新，不为每个尺度重新采样增强。
全局与worker随机种子沿用原流程；实验provenance记录完整策略、范围与版本。
推理不执行任何随机增强，也不改变raw/per-image的选择和评估工具。

```bash
git pull

```

```bash

```
