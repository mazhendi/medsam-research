# 验证记录

## 已执行

在 CPU 环境、Python 3.12、PyTorch 2.5.1 + torchvision 0.20.1 下：

- Ruff 静态检查。
- 13 项测试：数据与标签校验、重复图像与分组泄漏检测、边界/重叠指标、配置、清单生成、检查点约束，以及训练—评估—推理闭环。
- 真实 SAM 2.1 Hiera-Small 随机权重、64×64 输入，验证 batch=2 与逐图推理一致；任务 token 和解码器投影获得梯度，图像编码器无梯度。
- 官方 SAM 2.1 Hiera-Small 预训练权重、1024×1024 合成输入、batch=1，执行前向和反向传播。
- 使用同一官方权重，在三个独立合成样本上执行单轮训练、验证选择、权重保存、独立测试恢复，以及无标签 PNG 导出。这里只检查代码链路，不报告或解读这些随机图像上的分割分数。
