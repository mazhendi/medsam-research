# 当前精简增强：随机旋转、随机裁剪、水平翻转

按用户要求，仅保留以下三项，名称 `polyp_geometry`，版本1：

| 顺序 | 操作 | 参数 |
|---|---|---|
| 1 | 随机裁剪 | 概率0.5；宽高共同乘同一系数，均匀采样0.9～1.0；位置均匀随机；缩放回原输入尺寸 |
| 2 | 随机旋转 | 概率0.5；等概率选90°、180°、270° |
| 3 | 水平翻转 | 概率0.5 |

352基准尺寸时裁剪边长约317～352像素；90%指边长，非面积比例。
无显式垂直翻转，无亮度、对比度、饱和度、Gamma、噪声、模糊或遮挡。
90°倍数旋转沿用先前实现，不是连续任意角旋转。
图像和掩码同步裁剪/旋转/翻转。裁剪后RGB和软掩码仍用双线性缩放；不改变原软标签协议。
不按GT中心选位置，也不按GT决定是否接受裁剪；因此裁剪可能使部分目标离开视野。
增强应用在初始352缩放后、RGB标准化前；之后保留原256/352/448三尺度更新。
推理仍固定352且不做随机增强。模型、99轮、batch16、优化器和辅助权重保持。

主三头新版配置及运行：

```bash
git pull
medsam train-polyp-pvt --config configs/polyp_pvt_slots_three_head_geom.yaml
```

保存到 `runs/polyp_pvt_slots_three_head_geom`，不覆盖 `_aug` 或无增强结果。
用于公平对照的原Polyp-PVT配置为 `configs/polyp_pvt_1450_geom.yaml`。
可选无辅助配置为 `configs/polyp_pvt_slots_three_head_no_aux_geom.yaml`。
同一GPU按顺序运行，三组不是要求同时训练。
所有新配置相对对应无增强版仅改变增强名称和输出目录。
旧 `polyp_light` 及 `_aug` 配置保留原行为，不能将此前0.7779结果改标为精简增强结果。
该组既删除外观扰动和垂直翻转，又新增随机裁剪，不能当作旧组合的纯geometry-only消融。
范围为项目起始设置，尚无证据证明为ETIS最优；没有改变预测归一化或评估口径。

检查：49项相关测试通过，包括同步裁剪、精确旋转/翻转、无颜色变化、种子复现、
新配置隔离以及训练入口记录新策略并保持三尺度更新。尚未完成真实数据训练。
