# 阶段一：共享局部纠错分支

这是可训练的研究原型，不是已验证的新颖方法，也不包含动作收益预测器。首先验证：保持同一基线不变，细节读取和上下文读取是否能产生互补的区域纠错收益。

## 直接复用你的基线

仓库根目录运行，原始 SAM 2 权重与基线 best.pt 都需保留：

```bash
git pull
pip install -e ".[dev]"
medsam train-correction --config configs/retina_chase.yaml --checkpoint outputs/chase_observer1_seed42/best.pt --output outputs/chase_correction_v1 --epochs 20
```

Windows PowerShell 可以使用相同的一行命令。输出目录不能已存在。无需重新训练原基线。当前只提供训练和验证入口，实验设计确定后再加入锁定设置的测试评估。

## 结构

冻结整个已训练基线（编码器、任务 token 和分割解码器），提取全局 logits 与 SAM 2 最深层图像特征。每张图划分为 2×2 个不重叠的纠错中心区域：

- detail：读取与中心区域相同大小的原图窗口，缩放到 SAM 输入尺寸。
- context：在每侧扩展中心区域的一半宽/高，越界部分裁到图像边缘；编码后只对齐中心区域。

两个动作共享原有编码器及一个新纠错头。将全局/局部特征都对齐到中心区域的 128×128 网格，共享 1×1 卷积投影到 32 通道，拼接全局/局部 logits、logits 差和动作标识，经过两层 3×3 卷积与输出层，预测 logits 残差。最终将残差恢复到中心区域原图尺寸，加到原始全局 logits 上。

输出层零初始化，初始结果严格保持基线，避免先把全局 logits 缩小再放大带来的额外误差。此版本使用全局区域特征，并没有额外的全局 attention 模块。固定网格可能出现接缝，后续需根据图像检查，不能仅看平均分。

## 训练和选择

每个 epoch 遍历所有训练图，每图随机选择一个具有有效 FOV 像素的中心区域，对该区域分别执行两个动作。两个动作的原图网格 BCE+Dice 损失取平均，并加上 preservation 项：在基线二值判断正确的有效像素上，惩罚纠错前后概率变化的均方误差。默认权重 0.1，仅为可调整的实验初值，不能保证不会损害原本正确的预测，也不声称这一损失本身新颖。

默认 AdamW、学习率 1e-3、20 epochs、batch=1、FP32；基线提取无梯度，只有轻量纠错头训练。每个 epoch 在完整验证集上分别运行 global/detail/context，两个动作的验证 Dice 均值用于选择 checkpoint。零初始化的第 0 轮也参与选择，避免强制保存比基线更差的模型。保持测试集不参与此过程。

此实现逐窗口编码，不缓存局部特征；每个动作的验证路径需要一次全图和四次局部前向，两个动作联合验证复用全图，合计每图九次前向。不能将结果与单次基线推理视为等成本比较；本阶段目的是确认纠错能力与动作互补性，尚不优化选择策略。

## 回传结果

- summary.json：最佳轮次及 global/detail/context 的原图指标。
- initial_validation.json：零初始化一致性检查。
- history.jsonl：训练曲线。
- per_image.csv：各图各动作指标。
- per_region.csv：各中心区域在两个动作下的 Dice/Precision/Recall 差值，用于判断动作互补。
- 每个模式的 errors.png：红色漏分、蓝色误分、绿色真阳性。

分区指标受裁剪边界影响，不能把区域 clDice 直接当作整图拓扑；本版本仅记录区域 Dice/Precision/Recall。验证集只有四张图、两个儿童，不能据此做可靠的显著性结论。检查 preservation=0 消融、不同随机种子、更多受试者和等成本对照后，再评估是否值得增加动作收益预测器。
